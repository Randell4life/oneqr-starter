# გამოწერების ოპერირება

## ვადაგასული გამოწერები

Laravel scheduler ყოველ საათში გაუშვებს `subscriptions:expire` ბრძანებას. ბრძანება:
- ასრულებს ვადაგასულ `active`, `trialing` და `canceled` გამოწერებს;
- საცდელ გეგმას ასრულებს, როცა `trial_ends_at` გავა;
- გამორთავს `auto_renew`-ს;
- ბიზნესს ანიჭებს Free გეგმას, თუ სხვა მოქმედი გამოწერა აღარ დარჩა;
- უსაფრთხოა განმეორებით გაშვებისას და ინარჩუნებს გამოწერის ისტორიას.

სერვერზე Laravel scheduler-ის გასაშვებად დაამატე ერთი cron ჩანაწერი:

```cron
* * * * * cd /path/to/oneqr && php artisan schedule:run >> /dev/null 2>&1
```

ლოკალურ გარემოში ბრძანების ხელით გაშვება შეიძლება:

```bash
php artisan subscriptions:expire
```

## ფინანსური ანგარიშგება

პლატფორმის ადმინისტრატორს შეუძლია ნახოს გამოწერის გადახდების შეჯამება, თარიღების ფილტრი, სტატუსის ფილტრი და CSV ექსპორტი. ანგარიშგება ეფუძნება გადახდის ჩანაწერებს და არ ცვლის გადახდის ან გამოწერის სტატუსებს.
